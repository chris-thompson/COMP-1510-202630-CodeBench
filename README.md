### HOW SHOULD YOU STUDY A PYTHON FILE?
1. Read the comment (docstring) at the top of the file
2. Execute the program
3. Compare the program output with the code in the main function
4. Examine the file and its contents line by line top to bottom
5. When you examine something, don't just skim it:
    1. Describe what it does out loud to yourself, line by line (start to use the language of computing!)
    2. Name the functions, local variables, as they enter scope
    3. In each function identify arguments and return types, control structures, the types and helper functions being used
    4. Identify the goal of each program, function, and code snippet
    5. Try to represent the code with a flowchart
6. Modify the code in main, and predict what will happen BEFORE you execute it
7. Were you right?

### A NOTE ON AI (PLEASE READ)
AI coding assistants (ChatGPT, Claude, GitHub Copilot, Junie, and the like) are powerful, but in COMP 1510 they are **not allowed** when you are working on your labs, quizzes, or exams. You are here to learn how to program, and that means writing your own code. Turn inline AI completion off in PyCharm (the lab instructions show you how), and write a true/false pledge to this effect in your first quiz.

There is exactly **one exception: the term project!** For the term project you not only *may* use AI in any way you like (learning to apply it well to a large project is itself one of the things you are graded on), but you **must keep a log of how you use it**. The term project specification explains exactly what to record. Outside the term project, the rule is simple: the code you submit must be code you wrote.
